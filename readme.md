# Vibe Coded Python PDF Replacement Proof of Concept
I was doing some playing around wit ChatGpt and also Textual in Python, which is a text based terminal GUI (TUI) layer.
I wanted to see if I could create an SSH terminal based UI as a replacement for PDM while also testing the
Textual library to create a PASE app with a user interface.

## Set up for the environment
- Make sure all the IBM i Python 3.13 packages are installed.
- Create a Python virtual environment. You can use this link if needed to guide you on setting up a Python virtual environment.
https://github.com/richardschoen/howtostuff/blob/master/install-python-ibmivirtual-environment.md
- For this example we'll assume we've already created a Python virtual environment in directory: 
```/pythonenv313```
- Activate virtual environment
```source /pythonenv313/bin/activate```
- Install pip requirement 
```
pip3.13 install textual   
```
